# linecount

## Command description
linecount is a custom Linux terminal command combining 'cat' and 'wc'.
The command takes in one argument (being the file), and displays the contents, along with a line count. It can by requesting node, having the program command (being linecount.js), and giving it a text file to read (it would be something like: node linecount.js file.txt). It would be good to track how many lines a file has, or to see what is in those files.
